## Stockfish 19 — GPL-3.0

- **What:** the chess engine that computes every move evaluation, the bots' moves and the coach's advice. It runs in
  the browser as a separate program inside a Web Worker and talks to the app only through text UCI commands.
- **Package:** npm [`stockfish@19.0.0`](https://www.npmjs.com/package/stockfish/v/19.0.0) (the "lite
  single-threaded" WebAssembly build: `stockfish-19-lite-single.js` + `stockfish-19-lite-single.wasm`).
- **How it is shipped:** it is not stored in this repository. `apps/web/scripts/copy-engine.ts` (run automatically
  before `pnpm dev` / `pnpm build`, or by `pnpm engine:copy`) copies the two files from `node_modules/stockfish` into
  `apps/web/public/engine/` **together with the licence text** (`Copying.txt` → `LICENSE-stockfish.txt`), so the built
  site and the Docker image always serve the licence next to the engine.
- **Licence:** GNU General Public License v3.0 — <https://www.gnu.org/licenses/gpl-3.0.html>.
- **Source code (corresponding source of the distributed build):**
  - WebAssembly port by Nathan Rugg, tag **v19.0.0**:
    <https://github.com/nmrugg/stockfish.js/tree/v19.0.0>
  - Upstream engine by the Stockfish developers, tag **sf_19**:
    <https://github.com/official-stockfish/Stockfish/tree/sf_19>
- © the Stockfish developers (see the AUTHORS file upstream) and Nathan Rugg and contributors to stockfish.js.
