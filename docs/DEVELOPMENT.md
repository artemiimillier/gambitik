# Разработка и подробности / Development details

Этот файл — подробное руководство: запуск на Mac для ребёнка, все команды, e2e-тесты, режимы тренера, данные, приватность, голос и ИИ (выключены по умолчанию), API сервера. Коротко о проекте — [README](../README.md), устройство кода — [ARCHITECTURE.md](ARCHITECTURE.md), правила для участников — [CONTRIBUTING.md](../CONTRIBUTING.md).

> English: this is the detailed developer/operator guide (Russian). Short English overview — [README](../README.md#english).

**Важно:** всё, что ниже сказано про живой голос OpenAI, Codex, OpenRouter и «умного стратега», работает только с `GAMBIT_RUNTIME_AI=1`. По умолчанию (`GAMBIT_RUNTIME_AI=0`) в партии ребёнка нет генеративного ИИ и не нужен ни один ключ.

## Запуск

Нужны **Node.js 26+** и **pnpm 11**.

**Для ребёнка:** двойной клик по `Шахматы.command`. При первом запуске скрипт сам поставит зависимости и соберёт приложение, затем запустит сервер и откроет <http://127.0.0.1:8787>. Когда код обновился, скрипт при следующем запуске делает всё сам:
- доставит библиотеки, если изменился `pnpm-lock.yaml`;
- пересоберёт приложение, если исходники новее сборки;
- перезапустит уже работающий старый сервер, но только если 10 минут никто не играл. Иначе напишет «обновлю в следующий раз».

Если порт 8787 занят другой программой, скрипт назовёт её. Сервер остаётся работать в фоне. Остановить: `lsof -ti tcp:8787 -sTCP:LISTEN | xargs kill`. Флаг `-sTCP:LISTEN` нужен, чтобы не закрыть заодно браузер, у которого открыта вкладка. Если вкладка была открыта до обновления, обновите её: старая вкладка работает со старым кодом.

**Для разработки:**

```bash
pnpm install        # один раз
pnpm dev            # сервер :8787 + Vite :5173 (открывать http://localhost:5173)
pnpm build          # сборка SPA в apps/web/dist
pnpm start          # прод-режим: один процесс раздаёт API и SPA на http://127.0.0.1:8787
pnpm test           # Vitest по всем пакетам
pnpm typecheck      # tsc во всех пакетах + e2e
pnpm e2e            # Playwright: настоящий `pnpm dev` + Chromium (онбординг, партия, «верни ход», разбор, задачи)
pnpm e2e:prod       # Playwright: `pnpm build && pnpm start` на :8787 (SPA + движок + API одним процессом)
pnpm e2e:accounts   # Playwright: публичный сайт со входом (GAMBIT_ACCOUNTS=1), docs/ACCOUNTS.md
pnpm engine:copy    # Stockfish → apps/web/public/engine (само запускается перед dev/build)
pnpm puzzles:import # необязательно: импорт ≈ 50 000 задач Lichess (скачивает ≈ 300 МБ) → data/build/puzzles.sqlite; без него — 402 задачи из kb/
pnpm openings:build # генерация справочника дебютов
```

**E2E-тесты** (`e2e/`, конфиги `playwright.config.ts` и `playwright.prod.config.ts`) сами поднимают сервер с временной папкой данных (`DATA_DIR` во временном каталоге), `LLM_PROVIDER=template`, `CODEX_BIN=off` и пустыми `OPENAI_API_KEY` / `OPENROUTER_API_KEY` — ни настоящие данные ученика, ни подписка, ни платные API не затрагиваются. Порты 5173/8787 должны быть свободны (уже запущенный `pnpm dev` тесты не переиспользуют намеренно); если на 8787 работает ваш сервер (`Шахматы.command`), запускайте тесты на других портах: `GAMBIT_WEB_PORT=5174 GAMBIT_API_PORT=8788 pnpm e2e`, `GAMBIT_API_PORT=8788 pnpm e2e:prod`. Но `e2e:prod` пересобирает `apps/web/dist` — ту же папку, которую раздаёт ваш сервер, поэтому запускайте его, когда никто не играет. Один раз нужно скачать браузер: `pnpm exec playwright install chromium`. Скриншоты экранов сохраняются в `docs/screenshots/`; другой размер окна: `GAMBIT_E2E_VIEWPORT=1280x800 pnpm e2e`. В dev-режиме тесты читают состояние партии и задач через `window.__gambit` (в прод-сборку этот хук не попадает).

**Автоматика всегда беззвучна и бесплатна.** Если страницу ведёт Playwright/WebDriver (`navigator.webdriver`), приложение само выбирает беззвучный голос тренера, не создаёт звук и помечает запросы заголовком `X-Gambit-Automation: 1` — сервер для них не вызывает ни платный LLM, ни голосовую сессию (`/api/voice/session` и `/api/voice/live` отвечают 503, как без ключа), а их отчёты об использовании голоса не записываются. Включить звук в особом тесте: `localStorage['gambit.e2eVoice'] = 'on'` или `?e2eVoice=on`.


## Как Гамбитик помогает в партии

На шаге 3 мастера «Играть» ребёнок выбирает, как помогает Гамбитик:
- 🎓 **Учитель** — объясняет каждый ход и показывает хорошие ходы. В начале партии одной строкой называет стратегию, в каждой партии новую. Потом на каждом ходу даёт короткий совет со стрелкой и одной причиной «по плану». Ход всегда делает ребёнок. Подробно — [docs/TEACHER-MODE.md](TEACHER-MODE.md).
- 💡 **Подсказчик** — помогает, когда попросишь: кнопка «Подсказка» или вопрос голосом.
- 🏆 **Экзамен** — без подсказок, Гамбитик молчит до конца партии.

| Время партии | Режимы | Что выбрано на ступенях 1–4 / 5+ |
|---|---|---|
| Без часов, 10 минут, **5 минут** | Учитель, Подсказчик, Экзамен | Учитель / Подсказчик |
| 1 минута (молния) | выбора нет: Гамбитик только здоровается, поговорим после партии | — |

В партиях на 5 и 10 минут **часы ребёнка стоят, пока Гамбитик говорит**: совет, похвала, ответ на вопрос, предложение вернуть ход. Часы бота идут как обычно. Если ребёнок сделал ход, пока Гамбитик говорит, тот договаривает предложение (не дольше 2 с) и переходит к новому ходу. Выбор режима запоминается на 30 дней отдельно для каждого времени партии.

## Если Гамбитика не слышно

Этот раздел — для родителя. Что проверить, по порядку:

1. **Откройте приложение в Chrome или Safari** по адресу <http://127.0.0.1:8787>. Окно предпросмотра в Claude — не браузер ребёнка: там может не быть звука и микрофона.
2. **Сначала нажмите что-нибудь на странице.** Браузер не даёт звуку играть, пока на странице ничего не нажали. Мастер «Играть» и есть такое нажатие.
3. **Разрешите микрофон**, когда браузер спросит, — кнопка «Разрешить».
   - Если когда-то нажали «Блокировать», на кнопке у Гамбитика будет «Микрофон закрыт — нажми, чтобы разрешить». Над облачком появится записка «Браузер запретил микрофон» с шагами для вашего браузера.
   - **Chrome:** значок слева от адреса → «Микрофон» → «Разрешить», потом обновить страницу.
   - **Safari на Mac:** меню Safari → Настройки → Веб-сайты → Микрофон → у этого сайта «Разрешить».
   - **iPad:** «аА» слева от адреса → Настройки веб-сайта → Микрофон.

   Обычно Гамбитик подхватывает микрофон сам, без перезагрузки. Пока микрофон закрыт, Гамбитик говорит, но ребёнка не слышит.
4. **Проверьте звук и микрофон.** Откройте «Настройки»: замок родителя — нажать и держать 3 секунды или решить пример. Дальше «Голос Гамбитика» → «Проверка звука и микрофона»:
   - **«Проверить звук»** играет две ноты тем же путём, что голос Гамбитика;
   - **«Проверить микрофон»** 3 секунды слушает, показывает полоску громкости и отвечает «Я тебя слышу ✓» или говорит, что поправить: тихо, не тот микрофон, запрещён, занят Zoom или FaceTime.

   Обе проверки работают только на этом компьютере и бесплатны.
5. **Во время партии** над облачком может появиться большая кнопка **«Не слышно? Нажми сюда»**. Значит, голос пришёл, а страница его не проиграла. Нажмите её, и звук включится снова.
6. **Громкость Mac и куда идёт звук** (колонки или наушники). Проверьте, что у Гамбитика не выключен звук. Если на кнопке «Поговорить» написано «Лимит на сегодня», дневной лимит живого голоса исчерпан: его меняют в Настройках.
7. **«Сейчас говорит запасной голос — …»** в подсказке у Гамбитика и в Настройках. Это значит, что живой голос OpenAI не подключился. В строке написано почему (код в скобках) и когда будет новая попытка: через 1, 2, 4… минуты, но не реже раза в 15 минут, в начале следующей партии или разговора.
8. **Перебить Гамбитика:** нажмите на него, пока он говорит. С колонками то же делает кнопка «Поговорить». В наушниках ребёнок может просто говорить поверх.
9. **Выбрать голос:** Настройки → «Каким голосом говорит Гамбитик». Там 22 голоса OpenAI, сейчас стоит `marin`. Выбор действует со следующей голосовой сессии. «Послушать» произносит одну фразу платно, примерно 1–2 цента. Детского голоса среди них нет.
10. **Если ничего не помогло:** запомните время и подождите минуту, не закрывая вкладку. Потом возьмите файл `data/voice-diag.log`, «чёрный ящик» голоса. Слов ребёнка в нём нет.

## Структура

```
apps/web        @gambit/web      — Vite + React SPA (доска, экраны, маскот, движок в Web Worker)
apps/server     @gambit/server   — Hono на Node 26, только 127.0.0.1:8787 (хранилище, задачи, LLM, голос)
packages/shared @gambit/shared   — контракты типов (contracts.ts)
packages/core   @gambit/core     — анализ ходов и язык тренера (без DOM и node:)
packages/content @gambit/content — персонажи, программа, карточки понятий, промпты
packages/openings @gambit/openings — названия дебютов
tools           @gambit/tools    — импорт задач, сборка дебютов
e2e/            Playwright-тесты всего приложения
kb/             стартовый набор задач
data/           данные ученика (создаётся при работе, в git не попадает)
```

Пакеты подключаются как исходники TypeScript (`"exports": "./src/index.ts"`), шага сборки у них нет: Vite собирает их сам, а сервер запускается прямо из `.ts` — `node src/index.ts` (Node 26 сам убирает типы). Поэтому в коде только «стираемый» синтаксис (без `enum`, `namespace`, параметров-свойств), а относительные импорты пишутся с расширением `.ts`/`.tsx`. Импорт workspace-пакета из сервера работает без флагов и без `tsx`: симлинк pnpm ведёт в настоящую папку `packages/*` вне `node_modules`.

## Где лежат данные

Все данные ученика хранятся локально в `data/`. Сама папка закрыта для других учётных записей macOS (режим `0700`), файлы базы, профиля и журналов — `0600`.

- `data/app.sqlite` — база: партии, разборы, попытки задач, профиль, счётчик секунд голоса, мысли ребёнка после партии. Версия схемы — 3: сервер с более ранней схемой такую базу не откроет, поэтому перед откатом приложения сохраните копию файла.
- `data/games/ГГГГ/ММ/*.pgn`, `*.md` и `*.json` — PGN, подробный журнал и машинная копия каждой партии. Если был живой голос, в журнале есть и то, что ребёнок говорил тренеру, в том числе после партии («Мысли после партии»).
- `data/student/profile.md`, `data/student/progress.json` — профиль и прогресс ученика.
- `data/build/puzzles.sqlite` — импортированные задачи.
- `data/server.log` — лог сервера при запуске через `Шахматы.command`. Ключи и тексты ошибок внешних сервисов в лог не попадают.
- `data/voice-diag.log` — «чёрный ящик» голоса: только коды событий, без слов (см. «Если Гамбитика не слышно»).

**Партии взрослого.** Если за компьютером играли вы, откройте «Мои успехи» → «Все партии» → «Для взрослых» (замок родителя) → «Это играл взрослый». Такая партия остаётся в списке и в `data/games`, но не входит в прогресс ребёнка, в его сильные и слабые стороны и в профиль, который видят голос и ИИ. «Начать прогресс заново» отправляет все партии в архив и ничего не удаляет. Любую партию можно вернуть.

Если `data/app.sqlite` окажется повреждён, сервер не откажется запускаться: файл будет переименован в `app.sqlite.corrupt-<время>`, а приложение начнёт с чистой базы (журналы партий в `data/games` остаются). Собрать базу заново из файлов партий: `node tools/rebuild-db.ts --data-dir data --out <новый файл>`. Утилита пишет только в новый файл. Потом остановите сервер, отложите старый `app.sqlite`, положите новый файл на его место под именем `app.sqlite` и запустите сервер.

## Приватность: что и когда уходит с компьютера

**ИИ в партии ребёнка выключен по умолчанию** (`GAMBIT_RUNTIME_AI=0`, [docs/TEACHING.md](TEACHING.md) §4.4): ходы считает Stockfish, все слова написаны заранее. Сервер тогда берёт только шаблоны, не запускает `codex`, отвечает 503 на `/api/voice/live` и `/api/voice/session` и говорит браузеру «записанный голос» (`GET /api/health` → `ai.runtime: false`). Флаг сильнее `LLM_PROVIDER`, `VOICE_PREFERRED`, `CODEX_BIN` и ключей: ключ может оставаться в `.env` (Настройки покажут, что он есть), но не используется. Всё, что ниже про живой голос, Codex, OpenRouter и умного стратега, работает только с `GAMBIT_RUNTIME_AI=1`; строка запуска сервера пишет `runtime AI: off` / `on`.

Без ключей в `.env` и без установленного `codex` данные ребёнка никуда не отправляются. Одно исключение — голос компьютера (следующий абзац). Дальше — только то, что вы включили сами.

**Голос компьютера** (бесплатный, когда нет ключа OpenAI или живой голос не подключился) берёт лучший русский голос браузера. В **Chrome** это обычно сетевой голос Google, в **Edge** — сетевой голос Microsoft. Тогда текст фраз Гамбитика (не голос ребёнка) уходит на их серверы. В **Safari** на Mac голос работает на самом компьютере. Если на Mac установлен улучшенный русский голос (Milena Enhanced или Premium), Chrome обычно выберет его.

| Что включено | Кому | Что именно уходит |
|---|---|---|
| Живой голос (`OPENAI_API_KEY`, тренер в режиме «живой голос») | OpenAI (Live API `gpt-live-1` или Realtime API `gpt-realtime-2.1`) | **Звук с микрофона, пока открыта голосовая сессия** (в режиме «открытый микрофон» тренер слышит всё время партии — нужны наушники; в режиме «нажми и говори» — только пока нажата кнопка), реплики тренера, текстовые сводки позиции от приложения, псевдоним, род обращения, ступень программы и названия тем, над которыми идёт работа. Хранение у OpenAI выключено (`store: false`), но по правилам OpenAI журналы для защиты от злоупотреблений могут храниться до 30 дней. |
| ИИ-разбор партии через Codex CLI (подписка ChatGPT, `LLM_PROVIDER=auto` или `codex`) | OpenAI через ваш аккаунт ChatGPT | Ходы партии, оценки движка (классы ходов, ключевые моменты, мотивы), псевдоним, род, ступень, названия слабых тем, **сколько раз** ребёнок говорил с тренером. Слова ребёнка — **никогда**. |
| ИИ-разбор через OpenRouter (`OPENROUTER_API_KEY`) | OpenRouter → провайдер модели, с запретом сбора данных (`data_collection: deny`) | То же самое. Только текст; голос через OpenRouter не идёт. |
| ИИ-разбор через OpenAI API (запасной вариант, `OPENAI_API_KEY`) | OpenAI (Responses API, `store: false`) | То же самое. |
| Умный стратег режима «Учитель» (те же Codex → OpenRouter → OpenAI API) | Те же, что для разбора | Ступень, названия слабых и сильных тем, цвет фигур, имя бота и его сила, карточки стратегий из библиотеки, последние сыгранные стратегии; во время партии — позиция (FEN), ходы партии и 1–3 хода-кандидата движка с их объяснениями. Псевдоним и слова ребёнка — **никогда**. |

Что **не уходит никогда**: фамилия и другие личные данные (приложение их не спрашивает), журналы партий и `profile.md` как файлы, база данных, «чёрный ящик» голоса, ключи API. Имя, которое ребёнок ввёл на вопрос «Как тебя зовут?», уходит вместе с голосом и в разбор, поэтому лучше записать прозвище (Настройки → имя). Процесс `codex` запускается с «пустым» окружением: ключи из `.env` ему не передаются.

Слова ребёнка (расшифровка речи) записываются **только в локальный журнал партии**. В запрос на разбор они не попадают. Если вы хотите, чтобы разбор учитывал, о чём ребёнок спрашивал, поставьте в `.env` `REVIEW_INCLUDE_CHILD_SPEECH=1`: тогда провайдерам с API (OpenRouter / OpenAI API, но не Codex) будет отправлено до восьми коротких реплик, из которых вырезаны числа (телефоны, адреса), e-mail и ссылки.

Важно знать: правила OpenAI требуют особого режима (Zero Data Retention) для обработки персональных данных детей до 13 лет, а голос — персональные данные. Поэтому живой голос — осознанное решение родителя: псевдоним вместо имени, наушники, взрослый рядом. При сомнениях выберите в Настройках «Голос компьютера» и откройте приложение в Safari: там голос работает полностью на компьютере (в Chrome и Edge — см. абзац про голос компьютера выше).

## Записанный голос («Записи»)

В режиме «Записи» Гамбитик говорит заранее записанными фразами голосом Giselle: бесплатно, без микрофона и без интернета — для голоса с компьютера ничего не уходит. Совет собирается из записанных кусочков на естественных паузах: «Мой совет —» + «конём на эф шесть» + «— так мы давим на центр». Фигура и клетка берутся из хода движка, поэтому спутать фигуру он не может. Вместо разговора есть кнопка «Спроси» («Почему так?», «Что задумал соперник?», «Совет», «Повтори»), а после партии — кнопки «Как тебе партия?». Включается так: Настройки → «Голос Гамбитика» → «Записанный голос — бесплатно, без микрофона». В репозитории лежит только небольшой набор записей (`apps/web/public/voice/`, набор `pilot`); фразы, которых в нём нет, Гамбитик пишет в облачке. Как устроены записи и как записать новые — [docs/voice-clips/](voice-clips/) (`SPEC.md`, `ONDEMAND.md`). Лицензия записей — [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md): они не под AGPL.

## Как включить живой голос

1. Скопируйте `.env.example` в `.env` (файл не попадает в git).
2. Впишите ключ OpenAI API: `OPENAI_API_KEY=sk-...` (подписка ChatGPT голос не покрывает — нужен именно ключ API) и включите ИИ: `GAMBIT_RUNTIME_AI=1`, `VOICE_PREFERRED=live`.
3. Перезапустите сервер. `GET /api/health` покажет `voice.live: true`, `voice.realtime: true` и `voice.preferred`, и тренер заговорит живым голосом.

Голосов два, оба через OpenAI:

- **`live` (`VOICE_PREFERRED=live`)** — Live API, модель `gpt-live-1`: настоящий полный дуплекс, тренер слушает и говорит одновременно, его можно перебить. Браузер отправляет SDP-предложение на наш сервер (`POST /api/voice/live`), сервер создаёт сессию с настоящим ключом и возвращает SDP-ответ; ключ в браузер не попадает вовсе. Цена — $0.05 за минуту **открытой** сессии, включая тишину, плюс 15 секунд за каждое подключение.
- **`realtime`** — Realtime API, модель `gpt-realtime-2.1`: реплики по очереди с перебиванием, тишина бесплатна. Сервер выдаёт браузеру короткоживущий токен (`POST /api/voice/session`).

Модели меняются в `.env`: `VOICE_LIVE_MODEL`, `VOICE_MODEL`. **Голос** родитель выбирает в Настройках → «Каким голосом говорит Гамбитик», за замком родителя. Там 22 встроенных голоса `gpt-live-1`, 10 из них есть и у `gpt-realtime-2.1`. Выбор хранится на сервере и действует со следующей сессии. Голос из `.env` (`VOICE_LIVE_VOICE` / `VOICE_NAME`, сейчас `marin`) — это вариант по умолчанию. «Послушать» произносит одну платную фразу. Без ключа Гамбитик говорит голосом компьютера (см. «Приватность»).

**Если живой голос не подключился** (нет сети, сбой у OpenAI), сервер один раз повторяет запрос. Если и повтор не удался, говорит запасной голос: другая модель OpenAI или голос компьютера. К живому голосу приложение возвращается само в начале следующей партии или разговора: через 1, 2, 4… минуты, но не реже раза в 15 минут. Причина видна в Настройках и в `data/voice-diag.log` (см. «Если Гамбитика не слышно»).

**Сколько наговорили.** Приложение сообщает серверу секунды работы голоса. `GET /api/voice/usage` показывает эти секунды: `{ today, month, todaySeconds, monthSeconds, byProvider: { "openai-live": { todaySeconds, monthSeconds }, … } }`. Это оценка, а не счёт. Из чего складывается счёт:
- Live — $0.05 за минуту открытой сессии и минимум 15 секунд за каждое подключение;
- Realtime платится по токенам;
- «Послушать» стоит примерно 1–2 цента;
- стратегия и разборы через OpenRouter или OpenAI API — доли цента за вызов, отдельно от голоса.

Точная сумма — только в кабинетах OpenAI и OpenRouter. Чтобы не платить лишнего, платная сессия закрывается сама:
- в партии — через 2 минуты без действий ребёнка;
- вне партии — через 90 секунд тишины;
- в фоновой вкладке — через 15 секунд;
- при закрытии страницы — сразу;
- после дневного лимита родителя (по умолчанию 60 минут) — до полуночи.

Дневной лимит считает браузер. От «зациклившегося» переподключения защищает лимит сервера: не больше 10 новых голосовых сессий в минуту.

## ИИ-разборы партий

С `GAMBIT_RUNTIME_AI=1` `LLM_PROVIDER=auto` перебирает по порядку (без флага разбор всегда по шаблону): **Codex CLI** (ваша подписка ChatGPT, бесплатно сверх подписки) → **OpenRouter** (`OPENROUTER_API_KEY`, модель `OPENROUTER_REVIEW_MODEL`, по умолчанию `openai/gpt-5.6-terra`, запасная `openai/gpt-5.6-luna`) → **OpenAI API** → встроенный шаблон. Провайдер, у которого кончился лимит или кредиты, автоматически пропускается до восстановления (OpenRouter без кредитов — на 6 часов), так что разбор появляется всегда. Совет: заведите в OpenRouter отдельный ключ с месячным лимитом кредитов — это и будет потолок расходов. `GET /api/health` показывает `llm.openrouterKey`, `llm.openaiKey`, `llm.codexCli`, `llm.codexLoggedIn`.

Все оценки ходов ставит только шахматный движок; ИИ лишь пересказывает их простыми словами.

## Умный стратег режима «Учитель»

Каждую партию учитель ведёт по одной стратегии из библиотеки (`STRATEGIES` в `@gambit/content`, 24 карточки, каждая проверена Stockfish) — и каждый раз по другой. История ведётся **отдельно для белых и чёрных** (последние 5, в базе под ключом `strategy-history`): три последние стратегии этого цвета не предлагаются, пока есть из чего выбрать; каждая сыгранная партия считается, даже реванш через минуту. У каждой карточки 2–4 цели плана («бьём по цепочке пешек ударом цэ пять») — учитель держится их и после того, как соперник свернул с линии. Выбирает и формулирует короткую фразу умная модель:

- `POST /api/coach/strategy` — стратегия на партию и одна фраза до 20 слов («В этот раз разыграем Итальянскую партию — быстро выводим фигуры и целимся в слабую точку. Начни пешкой на е четыре.»). Белыми игра спрашивает её ещё в мастере, при нажатии цвета; чёрными — в момент, когда бот решил свой первый ход (настоящий ход, не догадка). Ответ — не позже чем через 8 с, первая строка партии ждёт его не дольше 8,5 с.
- `POST /api/coach/replan` — новый план и ход, когда соперник ушёл от плана или началась новая стадия партии (до 15 с; ответ несёт `ply`, устаревший игра выбрасывает). Ребёнок его не ждёт: свою короткую реплику игра говорит сразу, а новый план использует со следующего хода.

Провайдеры — те же, что у разборов (и так же подчиняются `LLM_PROVIDER`), но модель сильнее: **Codex CLI** с `CODEX_STRATEGY_MODEL` (по умолчанию `gpt-5.6-sol`, ваша подписка ChatGPT), **OpenRouter** с `OPENROUTER_STRATEGY_MODEL` (по умолчанию `openai/gpt-5.6-sol`, запрет сбора данных), **OpenAI API** (`OPENAI_STRATEGY_MODEL`), встроенный бесплатный выбор (ещё не игранная стратегия библиотеки, первый ход-кандидат движка и фраза по шаблону). **И стратегия, и перепланирование сначала идут через подписку Codex**:
- **стратегия:** Codex (ждём не дольше 7,5 с — `STRATEGY_CODEX_MS`, 3000–7800) → OpenRouter → OpenAI API → шаблон. `STRATEGY_CODEX_FIRST=0` ставит первыми API;
- **перепланирование:** Codex (9 с из 15) → OpenRouter → OpenAI API → шаблон.

Codex пропускается сам: исчерпан лимит — до времени сброса, которое сообщает CLI; не выполнен вход — 10 минут; три ошибки подряд — 5 минут; для стратегии — ещё и 30 минут после слишком медленного или ошибочного ответа (тогда первым идёт OpenRouter, чтобы вступление не ждало). Платный API для стратегии запускается, только если он ещё успевает ответить, иначе в срок отвечает шаблон. Sol думает «без размышления» (`none`): с `low` он не укладывается в срок (замер: Codex ≈ 6–8,5 с, OpenRouter ≈ 2,6–6 с). Почему Codex сейчас пропускается, видно в `GET /api/health` (`llm.codexPaused`) и строкой в Настройках. Кто придумал стратегию (провайдер, модель, «через подписку» / «платно» / «бесплатно») записано в журнале партии, строка «ИИ в этой партии».

**Сколько стоит.** Через подписку — бесплатно сверх подписки, но каждая партия с «Учителем» тратит один вызов Codex на стратегию (≈ 10 тыс. токенов недельного лимита) плюс перепланирования. Когда лимит исчерпан, всё само идёт через OpenRouter — **0,1–0,5 цента за вызов** (замер: стратегия ≈ 0,4 цента), несколько центов за партию в худшем случае. Отключить платные вызовы совсем: не ставить `GAMBIT_RUNTIME_AI=1` (так по умолчанию — тогда стратегия всегда из шаблона без клеток, история для разнообразия всё равно пишется) или `LLM_PROVIDER=template`. Автотесты (`X-Gambit-Automation: 1`) всегда получают бесплатный выбор и историю не меняют.

**Что проверяет сервер.** Модель только выбирает: `strategyId` — из кандидатов, которые посчитал код (цвет, ступень, первый ход соперника, разнообразие), `preferredUci` — из ходов-кандидатов движка. Фраза — по-русски, без латиницы и цифр, не длиннее 20 (15) слов, без часов, времени, цвета фигур, «чей ход» и «лучшего хода», и без клеток, которых нет в выбранном ходе, его объяснении или карточке стратегии. Любое нарушение — ответ следующего провайдера или шаблона. В лог пишутся только стратегия, провайдер, модель, оплата и время ответа: `[strategist] strategy london via codex gpt-5.6-sol (subscription) in 6840 ms (4 candidates)`.

## API сервера

Маршруты перечислены в конце `packages/shared/src/contracts.ts`. Сверх контракта сервер добавляет (описание — в `apps/server/src/routes/voice.ts` и `routes/games.ts`):

- `POST /api/voice/usage` — тело `{ "provider": "openai-live" | "openai-realtime" | "browser-tts", "seconds": число }` (прирост с прошлого отчёта — например, длина только что закрытой сессии; не больше 21600) → `{ "ok": true }`; как `application/json` или, когда страница закрывается, через `navigator.sendBeacon` как `text/plain` (только со своего адреса: Origin из списка или `Sec-Fetch-Site: same-origin`);
- `GET /api/voice/usage` — сводка расхода голоса (см. выше);
- `GET /api/voice/voices` и `PUT /api/voice/voices` `{ "voice": "<id>" | null }` — выбор голоса родителем: `{ selected, live, realtime, defaults, voices: [{ id, live, realtime }] }` (хранится в kv `voice.choice`; запрос автоматики ничего не меняет); `POST /api/voice/live` и `POST /api/voice/session` принимают необязательный `voice` — только для «Послушать»;
- `POST /api/voice/diag` — «чёрный ящик» голоса: `{ page, events: [{ t, e, …поля }] }` → строки в `data/voice-diag.log` (только короткие латинские коды; как `application/json` или маяком закрывающейся страницы; прочитать по HTTP нельзя);
- ответ 502 обоих голосовых маршрутов несёт `reason` — код причины (`net:<CODE>`, `timeout`, `http:<status>`, `nosdp`, `nosecret`);
- `GET /api/health` дополнительно сообщает `build` (коммит при старте, время старта, время сборки веба), `activity.idleSeconds`, `dataDirIsTemp` и `llm.codexPaused` — без путей и ключей;
- `GET /api/games/:id/review` дополнительно возвращает `keyTakeaways`, `suggestedTheme` и `suggestedThemeTitle` — чтобы экран разбора мог предложить «Порешать задачи на эту тему».

Маршруты контракта для списка партий и прогресса: `GET /api/games?limit=&offset=` (все партии, у каждой `excluded`), `GET /api/games/:id/journal` (журнал этой партии, только чтение), `PUT /api/games/:id/excluded` `{ excluded: 'adult' | null }`, `POST /api/student/reset-progress` `{ confirm: true }`, `POST /api/games/:id/thoughts` (мысли ребёнка после партии: только для трёх последних партий, до 20 за раз и 60 на партию, повтор не дублирует).

Все изменяющие запросы должны идти с `Content-Type: application/json` (иначе 415) и с того же origin; в прод-режиме (`NODE_ENV=production`) origin разработки `localhost:5173` не принимается. Ошибки внешних сервисов приходят в браузер как `{ "error": "voice-upstream", "status": <код> }` — без текста от внешнего сервиса.

## Свой сервер и аккаунты

Один контейнер (`Dockerfile` в корне): сервер Hono раздаёт API и собранный сайт на порту 8787 внутри контейнера. В образе нет ключей и платных функций: `GAMBIT_RUNTIME_AI=0`, `LLM_PROVIDER=template`, `VOICE_PREFERRED=clips`, `GAMBIT_CLIP_GEN=0`, `HIGGSFIELD_BIN=off`. Данные — в томе `/data`, записанные фразы можно подложить только для чтения в `/overlay`.

- Выкладка по SSH на свой сервер с Docker и обратным прокси (HTTPS) — [deploy/docker-ssh/](../deploy/docker-ssh/): настройки цели — в `deploy/docker-ssh/deploy.env` (в git не попадает).
- Аккаунты публичного сайта (`GAMBIT_ACCOUNTS=1`: ник + пароль, без почты, данные каждого ученика отдельно) — [ACCOUNTS.md](ACCOUNTS.md).
- За прокси нужны `GAMBIT_BIND_HOST=0.0.0.0` и `GAMBIT_PUBLIC_HOSTS=<ваш домен>` (подробно — комментарии в `apps/server/src/config.ts`).
